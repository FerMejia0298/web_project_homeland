Homeland

Proyecto desarrollado como parte del Sprint 6 del programa TripleTen.

Descripción

Homeland es una página web responsiva creada con HTML y CSS a partir de un diseño proporcionado en Figma. El proyecto presenta historias y fotografías de diferentes lugares del mundo mediante una estructura organizada en secciones y adaptada para dispositivos de escritorio, tablet y móvil.

Tecnologías utilizadas
HTML5
CSS3
Metodología BEM
Flexbox
CSS Grid
Media Queries
Git y GitHub
Características
Diseño responsivo para resoluciones de 1280 px, 768 px y 320 px.
Estructura semántica en HTML.
Organización de estilos por bloques siguiendo la metodología BEM.
Galería de imágenes mediante CSS Grid.
Efectos hover en elementos interactivos.
Adaptación visual basada en el diseño original de Figma.
